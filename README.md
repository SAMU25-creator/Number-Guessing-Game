# Number-Guessing-Game

A simple Python number guessing game where the player tries to guess a randomly generated number between 1 and 50.

## Features
- Random number generation
- Unlimited guessing attempts
- Hints when the guess is too high or too low
- Tracks the number of attempts

## How It Works
- The program randomly selects a number between 1 and 50.
- The player enters guesses.
- The game gives hints:
  - `"Slow Down!"` if the guess is too high
  - `"Goooo Higher!"` if the guess is too low
- The game ends when the correct number is guessed.

## How to Run

1. Make sure Python is installed.
2. Save the file as:

```bash
guessing_game.py
```

3. Run the program:

```bash
python guessing_game.py
```
